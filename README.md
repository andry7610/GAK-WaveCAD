# GAK-WaveCAD

![CI](https://github.com/andry7610/GAK-WaveCAD/actions/workflows/python-package.yml/badge.svg)

## Цепочка модулей

```
Осмос → Термалка → Акустика → Коллапс → Магноны → EM → Кросс-связи
  │         │          │          │          │        │        │
  │         │          │          │          │        │        └─ stability index, system status
  │         │          │          │          │        └─ TM/TE-моды, пьезосдвиг через d_piezo
  │         │          │          │          └─ Kittel + обменные моды, сдвиг через λ_s
  │         │          │          └─ фаза: STABLE / WARNING / COLLAPSE / INFLATION
  │         │          └─ сдвиг резонансных частот от суммарного напряжения
  │         └─ тепловое напряжение σ_thermal
  └─ осмотическое напряжение σ_osmotic
```

Напряжения от осмоса и термалки суммируются и передаются в акустический, магнонный и EM-модули.
Осмотическое давление передаётся в модуль коллапса как внешнее.
Coupling Monitor собирает результаты всех модулей и считает кросс-связи.

## Модули

### Osmosis Monitor
Осмотическое давление по формуле Вант-Гоффа: π = iCRT. Напряжение в оболочке: σ = πR / (2h).

### Thermal Monitor
Стационарный тепловой поток через сферическую стенку. Тепловое напряжение: σ = EαΔT / (1 - ν).

### Acoustic Monitor
Собственные частоты сферической оболочки:
- breathing (l=0) — радиальная мода
- flexural (l=1..5) — изгибные моды

Сдвиг частот под нагрузкой: f = f₀√(1 + σ/E).

### Born Collapse Monitor
Критическое давление коллапса (Зоэлли): P_cr = 2E/√(3(1-ν²)) × (h/R)².
Учёт несовершенств оболочки через imperfection_factor. Фазы: STABLE, WARNING, COLLAPSE, INFLATION.

### Magnon Monitor
Собственные частоты спиновых мод в YIG-оболочке:
- kittel (l=0) — однородная прецессия (формула Киттеля)
- exchange (l=1,2,3) — обменные моды

Магнитоупругая связь: механическое напряжение сдвигает частоты через магнитострикцию λ_s.
Добротность Q определяется затуханием Гилберта α.

### EM Resonance Monitor
Электромагнитные моды сферического резонатора:
- TM-моды (корни сферической функции Бесселя j_l(x) = 0)
- TE-моды (корни производной [x·j_l(x)]' = 0)

Пьезоэлектрическая связь: механическое напряжение генерирует электрическое поле, сдвигающее EM-частоты через коэффициент d_piezo.
Добротность Q = 1/tan(δ).

### Plasma Monitor
Термоядерный синтез: реактивности D-T и D-D по Bosch-Hale, тормозное излучение, магнитное поле.
Энергобаланс: P_alpha - P_rad - P_cond - P_sync = dE/dt.
Критерий Лоусона: n·T·τ_E ≥ threshold.

### Vacuum Monitor
Давление газа P = nkT, вязкостный и молекулярный режимы откачки, длина свободного пробега.

### Quantum Vacuum Monitor
Эффект Казимира (энергия между пластинами) и эффект Швингера (рождение пар в сильном поле).

### Bio Bridge
Био-акустический мост: нейронная активность → сдвиг акустических частот.
Обратная связь: плазма → био-активность.

### Coupling Monitor
Метамодуль — считает кросс-связи между всеми модулями:
- k_magnetoelastic — акустика ↔ магноны
- k_piezoelectric — акустика ↔ EM
- k_magnetoelectric — магноны ↔ EM
- k_thermal_osmosis — термалка ↔ осмос
- k_plasma_vacuum — плазма ↔ вакуум
- k_plasma_thermal — плазма ↔ термалка (через dE/dt)
- k_bio_acoustic — био ↔ акустика
- k_bio_plasma — био ↔ плазма
- k_plasma_quantum — плазма ↔ квантовый вакуум (через pair_rate)
- geom_factor — влияние коллапса на геометрию

Выдаёт общий индекс стабильности (0..1) и системный статус: HEALTHY, DEGRADED, CRITICAL.

## Запуск

### Простой запуск (Windows)
Дважды кликните `start.bat` — запустит Streamlit-сервер и откроет браузер.

### Ручной запуск (веб-интерфейс)

```bash
pip install streamlit numpy scipy pyyaml matplotlib optuna
streamlit run app.py
```

### CLI — полная цепочка

```bash
python run.py
```

### Демо с графиками

```bash
python demo.py
```

## Физика одним блоком

* **Каскад**: фаза зажигания (высокий pair_rate по Швингеру) → плавный переход 5% →
  фаза горения (низкий pair_rate, авто-подкачка).
* **Лоусон** считается по плотности *топлива*: гелиевая зола разбавляет рабочую смесь,
  n_fuel = n·(1 − f_He), мощность ∝ (1 − f_He)².
* **Зола**: равновесная доля f_He из баланса рождение/откачка; pump_speed — настоящая
  ручка откачки, а не декорация (v37).
* **Вольфрам**: бремсштрулунг умножается на Z_eff ≈ 1.54 — грязная плазма, как в жизни.
* **Objective**: −P_net (чистая электрическая мощность после каскада КПД и налога
  рециркуляции ~ (B·v)² на криогенику и ALIP-прокачку).
* **MHD-бета**: мягкий штраф выше потолка; β топ-пятёрки v37.2 упиралась в 0.08 —
  поэтому в v38 потолок поднят до 0.12.

## Оптимизация

* **Сэмплер**: TPESampler(seed=43, n_startup_trials=10), **прунер**: MedianPruner
  с репортами чистой мощности на 50–87.5% шагов (на разогреве триал не судим).
* **AI-фильтр**: трансформер (`ai_predictor_DT.json`) отсеивает явный брак
  (runaway, холодная плазма, нет рождения пар); физика — финальный арбитр.
* **Сиды**: чемпионы прошлых прогонов в очереди, первым — trial 37 (597.24 МВт).
* **Storage**: SQLite (`models/optuna_study.db`) — прогресс не теряется при
  перезагрузке страницы; `models/STOP_FLAG` — мягкая остановка прогона.
* **Хранение истории**: экспорт триалов и лучшей точки в `results/` после прогона.

## Запуск

```bash
pip install streamlit optuna numpy pandas
python app.py                # веб-интерфейс (Streamlit)
python optuna_optimizer.py   # ночной прогон оптимизатора (80 trials, ~1.5-2 ч)
```

## Тесты

```bash
pip install pytest
python -m pytest tests/ -v
```

204 теста: физика зажигания/горения, Лоусон, зола и вольфрам (`test_optuna_ash.py`),
вакуум, биомост, квантовый вакуум, кориолис, устойчивость к возмущениям, граничные
случаи (no NaN, no crash).

## Эволюция версий (кратко)

* **v9.3 → v11** — constraint pl_radius, золотая зона границ из 50 триалов, сиды.
* **v15** — каскадная оптимизация «зажигание → горение» с плавным переходом.
* **v20–v26** — динамический pl_radius с safety-check, расширение границ, брейкивен.
* **v31–v34** — честный энергобаланс станции (Q_plasma, f_ext, тритий, когенерация),
  фикс размерностей, прунер на единой шкале мощности.
* **v35–v36** — мягкая остановка STOP_FLAG, рециркуляция ~ (B·v)², β-метрика MHD.
* **v37** — грязная плазма: гелиевая зола (C_ASH калибрована на рекорде 1527 МВт),
  вольфрам Z_eff, pump_speed — настоящая ручка.
* **v37.2** — objective → P_net: налог рециркуляции, фикс pump_speed из
  vacuum_monitor, прунер и success-сообщения на чистой мощности.
* **v38.0** — снятие β-стены: потолок 0.12, external_B до 35 Тл, 80 триалов,
  сид-чемпион trial 37 первым в очереди.

Полная история — в CHANGELOG.md.

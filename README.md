# GAK-WaveCAD

## Результаты (17.11.2026)

Сферический термояд с волновым удержанием: LCOE оптимизирован Optuna TPE
с сидовой лестницей физически откалиброванных конфигураций.

Прогрессия чемпиона: 113.40 → 104.52 → 100.64 → 99.59 → 96.66 → 95.11
→ 93.70 → **85.96 $/МВт·ч** (−24.2% за сидовую лестницу S2→S35).

Финальная конфигурация (S35, trial 33):
R = 2700 мм, B = 14 Тл, n = 5.86e20 м⁻³, β = 0.145,
wall load = 24.2 МВт/м² (лимит C/C-SiC adv 25), P_net = 1471 МВт.

Сценарии (верифицированы сидами-контролями бит в бит):
- сварной силовой корпус ЭК-181/EUROFER-97 (blanket ×0.7): 87.66;
- + внутренний эмиттер (magnets ×0.5): **85.96**.

Валидация: 35 сидов воспроизводятся бит в бит между релизами;
гейты зажигания и золотой зоны отрезают нефизичные точки (1e10);
TPE с реэнкью-клонами не теряет чемпиона.

Контур на горизонте: точка с raw LCOE 81.7 найдена разведкой (T49), но требует
материала стенки ≥33 МВт/м² и β-потолка ~0.25 — следующий рубеж физики.

## ⚠️ ВАЖНО: характер результата 85.96 $/МВт·ч

**LCOE 85.96 $/МВт·ч — это NOAK-оценка** (n-th-of-a-kind): серийная станция
после кривой обучения, с оптимистичными допущениями экономики
(blanket 16.03 млн $/м², BOP 3900 $/кВт, каскадный КПД 0.669, CF 0.85,
дисконт 7%). Это **не** первый образец (FOAK): по литературе FOAK-станции
оцениваются в 150–200 $/МВт·ч, референсная модель DEMO — 115–160 $/МВт·ч.

Паспорт надёжности (v46R, подтверждён 17.11.2026, все проверки — в `v46R_validation.py`):

| Проверка | Результат |
|---|---|
| База S35 | 85.9592 $/МВт·ч — независимая реконструкция экономики сходится до 6-го знака |
| Run A — чувствительность | Критичны: BOP (±42.0 $), дисконт (±31.7), КИУМ (±31.3); blanket ±14.1; каскад ±3.6; криогеника ±0.06 |
| Run B — слепой прогон | 50 триалов, **ноль сидов**, чистая БД: best **86.81**, медиана 109.93, успешных 14/50 — рекорд не подгонка |
| Run C — граница физики | wall 25/30/35 МВт/м²: best одинаково 98.2113 — лимит стенки не активен, 85.96 не жертва материалов |

**Вердикт: 85.96 $/МВт·ч подтверждена как реальный оптимум модели, а не артефакт сидов или ограничений.**

Воспроизвести: `python v46R_validation.py runa` (ёжик + tornado), `runb` (слепой прогон, отдельная чистая БД `results/blind_v46R_runb.sqlite`, сиды заглушены), `runc` (граница физики).

### Материальная спецификация силового корпуса (постановление штаба, 15.11.2026)

Силовой корпус — сварной, из малоактивируемой ферритно-мартенситной стали (RAFM):
ЭК-181 / RUSFER-EK-181 (Fe–12Cr–2W–V–Ta–B, ВНИИНМ, РФ) либо EUROFER-97 (9Cr–1W–VTa, ЕС).
Первая стенка — черепица C/C-SiC (c_c_sic_adv: лимит 25 МВт/м², наценка 15%).

Почему RAFM вместо аустенита (316L/N):
- аустенит при DEMO-дозах (>70 сна, нейтроны 14.1 МэВ) распухает неприемлемо;
  ФМ-решётка практически не распухает до 100 сна (ЭК-181, облучение БОР-60);
- малоактивируемость: Mo/Nb заменены на W/Ta — рециклинг вместо 500-летнего
  захоронения (ЭК-181: спад активности до уровня рециклинга за десятилетия);
- сварной шов ЭК-181 исследован и держит мартенситную структуру — сварка
  лепестков дешевле и реалистичнее монолитной отливки сферы Ø5 м.

В модели: экономический флаг `welded_vessel` (v46Q) — cost_blanket × 0.7.
Расчёт по компонентной модели на геометрии чемпиона: −6.1…−6.5 $/МВт·ч.
Ограничение честности: ФМ-стали склонны к радиационному охрупчиванию при
низких температурах и распаду твёрдого раствора Cr (~30 сна) — окно
эксплуатации 350–550 °C, у ODS-вариантов до 650 °C.

**v46R** — цифровой двойник сферической термоядерной станции (D-T) с каскадом
«зажигание → горение», честным энергобалансом, экономической моделью LCOE
и Optuna-оптимизацией на TPE с сидовой лестницей.

## Физика одним блоком

* **Каскад**: фаза зажигания (высокий pair_rate по Швингеру) → плавный переход 5% →
  фаза горения (низкий pair_rate, авто-подкачка).
* **Лоусон** считается по плотности *топлива*: гелиевая зола разбавляет рабочую смесь,
  n_fuel = n·(1 − f_He), мощность ∝ (1 − f_He)².
* **Зола**: равновесная доля f_He из баланса рождение/откачка; pump_speed — настоящая
  ручка откачки, а не декорация (v37).
* **Вольфрам**: бремсштрулунг умножается на Z_eff ≈ 1.54 — грязная плазма, как в жизни.
* **Objective (v46R)**: LCOE станции, $/МВт·ч — оптимизатор минимизирует стоимость
  энергии, а не гонит мощность в потолок (исторически: v31–v38 — P_net/P_fusion).
* **MHD-бета**: мягкий квадратичный штраф в LCOE-объективе; потолок 0.15
  (поднимался по мере перехода на LCOE-шкалу: 0.08 → 0.12 → 0.15).
* **Гейты (v46Q)**: golden zone pl/R ∈ [0.42, 0.52] и жёсткий Гринвальд
  (n ≤ n_G, pl в метрах) — нефизичные точки отрезаются до физики (1e10).

## Оптимизация

* **Сэмплер**: TPESampler(multivariate=True, group=True, seed=43) — статичная
  сигнатура сидов и разведки (v46O/v46Q); реэнкью 10.
* **Прунер**: MedianPruner с репортами на LCOE-шкале.
* **Сиды**: сидовая лестница S2–S35 — физически откалиброванные конфигурации,
  верифицируются бит в бит между релизами (контрольные точки Run20: 31/31).
* **Экономические флаги (v46Q)**: `welded_vessel` (blanket ×0.7),
  `emitter` (magnets ×0.5) — в `_pkey` и прескрин-ключе (иначе дедупликация
  съедает копии сидов).
* **Storage**: SQLite (`models/optuna_study.db`), свежее study на каждый релиз
  (`gak_opt_{mode}_v46Q`); `models/STOP_FLAG` — мягкая остановка прогона.
* **Хранение истории**: экспорт триалов и лучших точек в `results/`;
  каноническая летопись — `history_project_full.md` (v9.3 → v46Q).

* **v31–v34** — честный энергобаланс станции (Q_plasma, f_ext, тритий, когенерация),

* **v37.2** — objective → P_net: налог рециркуляции, единая шкала прунера. Рекорд
  597.24 МВт чистыми (trial 37); обнаружена β-стена 8%.
* **v38.0** — снятие β-стены: потолок 0.12, external_B до 35 Тл, 80 триалов,
  сид-чемпион trial 37 первым в очереди.

  Восстановление — по шапкам старых файлов и логам прогонов.

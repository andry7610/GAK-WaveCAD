# GAK-WaveCAD

**Демонстрационная версия модели волнового контроля плазменной системы GAK-WaveCAD.**

Про моделирует связанную физическую систему из 7 модулей: осмос, теплообмен, акустика, коллапс, магноны, электромагнитный резонанс и кросс-связи между ними. Каждый модуль реализует единый интерфейс: `init() -> run() -> get_results() -> print_report()`.

## Модули системы

| Модуль              | Описание                                      |
|---------------------|-----------------------------------------------|
| **Осмос**           | Перенос вещества через мембрану               |
| **Теплообмен**      | Тепловое распределение и баланс энергии       |
| **Акустика**        | Волновое распространение в среде              |
| **Коллапс**         | Модель коллапса (Born collapse)               |
| **Магноны**         | Спиновые волны в магнетике                    |
| **EM-резонанс**     | Электромагнитный резонанс плазмы              |
| **Кросс-связи**     | Связи между всеми модулями, проверка стабильно|

Цепочка передачи данных: осмос > теплообмен > акустика > коллапс > магноны > EM-резонанс > кросс-связи.

## Установка

### Требования

- Python 3.10+
- Зависимости: `numpy`, `scipy`, `matplotlib`, `pytest`

### Запуск

```bash
# Клонировать репозиторий
git clone https://github.com/andry7610/GAK-WaveCAD.git
cd GAK-WaveCAD

# Установить зависимости
pip install -r requirements.txt

# Запустить отдельный модуль
python tests/run_thermal_test.py

# Запустить все юнит-тесты
python -m pytest -v

# Запустить интеграционный тест вручную
python tests/test_integration.py
```

## Тестирование

### CI (GitHub Actions)

При каждом пуше автоматически запускаются:

1. **6 отдельных скриптов** (`run_*.py`) — каждый тестирует свой модуль
2. **pytest** — 49 юнит-тестов плазменного монитора + 1 интеграционный тест = **50 тестов**

Интеграционный тест проверяет:
- Корректную передачу данных между всеми 7 модулями
- Ненулевые кросс-связи между модулями
- Стабильность системы в диапазоне 0-1
- Валидный статус системы

### Локальный запуск

```bash
# Все тесты pytest
python -m pytest -v

# Только плазменный монитор
python -m pytest tests/test_plasma_monitor.py -v

# Интеграционный тест
python -m pytest tests/test_integration.py -v
```

## Архитектура

Каждый модуль следует единому интерфейсу:

```
init()        # инициализация параметров
run()         # расчёт
get_results() # возврат результатов
print_report()# вывод отчёта
```

Данные передаются по цепочке: выход одного модуля — вход следующего. Кросс-связи проверяют, что ни одна связь не равна нулю и система остаётся стабильной.
